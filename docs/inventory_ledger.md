# 재고 수불·실사

경로: `/inventory/ledger` (재고관리). 월간 집계, 유형별 집계, 품번별 일별 잔고와 전표/LOT 상세, 기초/실사 입력, 수불 보완, 수정 이력, XLSX 다운로드를 제공한다.

참고 양식은 `선반공정 재고실사표_2026년 09월_26.10.01.xlsx`와 `가공단자 일일재고현황_20261001.xlsm`이다. 매크로를 실행하거나 파일 내용을 초기 데이터로 적재하지 않는다. 두 파일의 본표에는 2026년 9월 기준 자료가 있으므로 파일명만으로 데이터 기간을 정하지 않는다.

## 계산 및 저장

- 월간 계산재고 = 기초 + 입고 − 출고. 기초 미입력은 계산재고도 미입력이다. 0은 입력된 값이다.
- 실사 차이 = 실사수량 + 실사 이월수량 − 실사일까지의 장부재고. 월 중간 실사도 해당 일자까지 계산한다.
- 실사 이월수량은 원본 월말 양식의 별도 합산 수량이다. 다음 달 기초로 불러오는 동작과 구분한다.
- 전월 기말 불러오기는 전월 말일 실사가 있으면 실사+실사 이월수량, 없으면 전월 계산재고를 제안한다. 사용자가 확인한 후 현재 월에 저장하며 과거 월 수정이 후속 월 기초를 자동 변경하지 않는다.
- 원장 품번은 내부 품목 ID로 연결하고 현재 품목마스터 품번/품명을 표시한다. 외부 미연결 품번은 수량과 공정을 표시하되 이름을 외부에서 가져오거나 임의 매칭하지 않는다.
- EA, kg 등 단위가 다른 품목의 총수량을 합산하지 않는다.
- 기초/실사 저장, 보완 입력/취소는 새 검토용 테이블 3개에만 저장한다. 기존 LOT, 재고조정, 출고, 수주 수량을 변경하지 않는다. 실제 재고조정은 기존 메뉴에서 별도 처리한다.
- 기초/실사 변경에는 버전 확인을 적용하고 이력을 남긴다. 보완 내역은 삭제 대신 사유를 남겨 취소한다.

## 자료 구분과 집계 범위

내부 MES와 외부 연동 자료는 선택해서 조회하고 합치지 않는다. 동일 거래 중복 식별 정책은 변경하지 않았다. 각 자료 구분마다 기초/실사/보완을 독립 저장한다.

| 원천 | 집계 |
| --- | --- |
| 내부 구매 | 확정 입고일 기준 구매입고 |
| 내부 생산 | 생산일 기준 총생산 입고, 생산불량/SET-UP 출고, 소비원장 기준 자재/반제품 투입 |
| 내부 외주 | 확정 출고일 기준 이전 품번 차감, 입고일 기준 가공 후 품번 증가 |
| 내부 포장 | 포장일 기준 투입 생산 LOT 품번 차감, 포장 BOX 기준 완제품 증가 |
| 내부 출고 | 확정 출고일 기준 출고. 직출고는 원생산 품번에서 차감 |
| 내부 불량/조정 | 활성 재고불량, 재고조정. 창고 이동은 전체 품번 재고 증감에서 제외 |
| 외부 생산 | 기존 품번 매핑 사용. 수신 생산/불량/SET-UP 집계. SET-UP 미수신은 확인사항 표시 |
| 외부 외주 | 현재 존재하는 입고검사 스냅샷의 확정일 기준 ORI_LOT_QTY 입고 및 불량/LOSS/샘플/킵업 차감 |
| 외부 포장/출고 | 현재 존재하는 포장 및 확정 출고 LOT 기준. 포장 데이터의 누적 출고수량을 별도로 차감하지 않음 |

외부 자료에는 구매입고·외주출고·공정투입 원장이 모두 없으므로 수불 보완이 필요하다. 부족한 원천을 BOM으로 추정하거나 다른 행의 값을 복사하지 않고, 계산재고가 검토용임을 화면과 내보내기에 표시한다. 네 가지 연동 자료만으로 완전한 과거 재고를 재현했다고 주장하지 않는다.

## 권한과 배포

`/inventory/ledger` 메뉴 READ는 조회/상세/이력/내보내기, WRITE는 저장과 보완/취소까지 허용한다. 관리자 외 계정은 사용자 관리에서 새 메뉴 권한을 지정한다. API에서도 권한을 검사한다.

모델 초기화 시 `inventory_ledger_balances`, `inventory_ledger_entries`, `inventory_ledger_audits`를 새로 생성한다. 기존 테이블 데이터와 첨부 파일은 수정하지 않는다.

검증: `tests/test_inventory_ledger.py` 및 기존 재고 이동·재고 조회·출고대기·품명 매핑 테스트. 별도 임시 DB에서 브라우저로 월간/일별, 실사 저장, 보완·취소, 이력, 자료 구분을 확인했다.

## 월간 양식

월간 기본 표와 XLSX 첫 시트는 3단 헤더로 구분·품번·단위·기초·입고, 생산(생산/불량/Setup), 외주가공(입고/불량/LOSS/샘플), 포장·원재료·출고·기말(산출), 재고실사(실재고/이월수량), 차이를 표시한다. 기말(전산)은 사용자 요청으로 제외했다. 품명은 화면 품번 툴팁과 상세, XLSX 실사 상세에 남긴다. 고정 열에 없는 킵업·공정투입 등도 입출고 총합 및 기존 유형별/일별/전표 상세 집계에 포함한다. 원재료 열은 구매입고 수량이다. 다단 헤더 첫 시트의 필터는 사용하지 않고, 나머지 평면 상세 시트에는 필터를 유지한다.
