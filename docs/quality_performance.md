# 품질실적

현재 화면은 원본 17개 시트의 배치를 유지하며, MES에 보관된 입고·공정·외주·조립 자료를 집계해 해당 셀과 차트에 표시합니다. 전월을 기본 조회하며 보고 월·자료 구분을 변경할 수 있습니다. 외부 연동과 MES 입력은 각각 선택해서 조회하며 합산하지 않습니다.

양식 정의는 `scripts/build_quality_form.py`로 생성하고 `static/quality_performance_form.json`에 보관합니다. 원본 XML의 그림 관계를 읽어 요약 차트 2개를 포함한 28개 차트 위치를 보존합니다. 실적 화면은 `/api/quality/performance/form`을 호출하며, Excel 출력과 동일한 `build_excel` 결과에서 셀의 계산값·숫자 서식·차트 데이터를 가져옵니다. 원 단위 매출은 원본 숫자 서식대로 천원으로 표시합니다. `app.py`가 앱 생성 직후 품질실적 라우터를 직접 등록합니다. 화면과 조회·저장·출력 API가 안내 화면 라우터의 내부 등록에 의존하지 않습니다.

납품·고객불량·매출·클레임은 저장된 수기 값이 없으면 공란입니다. 아직 수기 입력 UI를 새 양식에 연결하지 않았으며 자동으로 추정하거나 0으로 저장하지 않습니다. 조회는 생산·재고·출고 원장을 변경하지 않습니다. 2024·2025 비교 실적은 제공된 원본 파일의 참고값이며 화면 확인사항에 출처를 표시합니다. 당월 이후 실적은 공란입니다. 분류되지 않은 자료는 집계 확인사항에서 확인합니다.

이번 화면 연결은 임시 DB를 사용한 테스트 26개와 실제 앱 브라우저에서 시트 전환·자동 셀 값·수기 공란·자료 구분 분리·Excel 다운로드를 검증했습니다. 사용자 PC 운영 수치 대사는 별도 확인이 필요합니다.

## 사용자 확인 집계 기준

- 목표: 원자재 입고 0.3%, 공정 0.3%, 외주 0.7%, 최종검사 0.8%, 고객 10 PPM, 발생 클레임금액/매출액 1%.
- 원자재 불량은 0. CAP은 280098, YR280554/555/556/589, SEAL은 480187/480207. 동소재는 원본 자재유형 ‘동소재’입니다.
- 공정불량은 복합선반·탭핑만 집계합니다. 조립은 공정 표의 기존 행을 0으로 두고 최종검사에만 집계합니다.
- 최종검사의 SV1/AX1-EV는 내부 품명에 해당 문구가 포함되는 조립실적입니다. 310061/310067/310070 묶음과 310140은 품번 및 BOM 상위 품목 연결로 판별합니다. 연결 불명확한 품목은 확인사항에 표시합니다.
- 생산수량은 양품+불량+셋업, 불량 분자는 불량수량입니다. 셋업 수량을 임의로 불량유형에 합산하지 않습니다. 이 기준은 기존 MES 불량 현황의 수량 기준을 따릅니다.
- 여러 LOT에 공유되는 조립 불량 유형은 묶음당 한 번 합산합니다. 유형 미분류·유형 합계 불일치는 기타에 포함해 총 불량수량을 맞추고 확인사항을 명시합니다.
- 외주는 메인텍/혜성금속에 연결되는 검사 확정일(외부) 또는 입고일(내부)의 수량을 사용합니다. 업체/수량/유형 미연결은 확인사항입니다.
- 자동 집계 자료는 외부 연동 또는 MES 입력 중 한 가지를 선택합니다. 동일 거래로 추정해 합치거나 두 원장을 무조건 합산하지 않습니다.

## 수기 입력과 저장

월별 납품수량, 고객 불량수량/건수, 매출액, 3개 품목군의 클레임 발생/합의/공제금액, 작성자, 분석 의견을 보관합니다. 금액 입력·저장은 원 단위입니다. 원본 매출액 셀의 숫자 서식 `#,##0,`가 천원으로 표시하므로 그대로 보존하며, 클레임 금액 셀은 원 단위로 표시됩니다. 클레임율 분자는 발생금액입니다. 원본 시트6에는 의견 작성 영역이 없어 클레임 의견은 화면 메모로 보관합니다.

MES에 보관할 수기 실적은 화면에서 저장합니다. 다운로드한 Excel에서 시트 5·6을 직접 작성해도 월별·누계·PPM·클레임 비율이 다시 계산되도록 수식을 유지합니다.

빈칸은 미입력, 0은 실제 0입니다. 미입력 월이 있으면 고객/재무 연간 누계·비율을 완전한 실적으로 표시하지 않습니다. 월별 입력은 다른 달을 덮지 않으며 버전 충돌 검증과 이전/이후 수기 내용 감사 이력을 보관합니다. 자동 집계는 조회 시 원장을 기준으로 갱신하며 확정 마감 스냅샷 기능은 아닙니다.

독립 `quality_performance_months`, `quality_performance_audits` 테이블에 저장합니다. 입고·재고·생산·출고 원장을 변경하지 않습니다.

## 원본 Excel 보존

`assets/QualityPerformance_Template.xlsx`는 사용자가 제공한 원본입니다. openpyxl로 다시 저장하지 않고 ZIP 내부의 해당 셀/수식 캐시와 차트 데이터 캐시만 갱신합니다. 시트 이름·순서 17개, 차트 파일 28개, 스타일, 병합, 열너비/행높이, 도형 위치, 인쇄 설정과 패키지 파일 구성을 유지합니다. 표지 도형의 연도·월 글자만 보고 대상 월로 바꿉니다. lxml이 필요합니다. 원본에서 고정 숫자 배열을 쓰던 차트 3개는 대응 셀 범위를 참조하도록 바꿔 원장과 목표 변경이 반영되게 했습니다.

원본의 다음 참조는 동일한 셀과 서식을 유지한 채 수정했습니다.

- 작성일과 별개로 선택한 실적 월을 당월 지표·차트 보조값에 적용합니다. 1월 전월은 이전 연도 칸을 참조합니다.
- 고객 당월 지표는 발생 건수가 아니라 PPM 행을 참조합니다.
- 클레임 요약은 4월 고정 칸이 아닌 보고 월을 참조합니다.
- 외주 유형별 보조값은 3월 고정 칸이 아닌 보고 월을 참조합니다.
- 최종검사 품목별/유형별 표는 같은 조립 원장을 사용합니다.
- 최종검사 증감은 당월−전월입니다. 미입력 고객/재무 항목과 0 분모는 공란으로 표시합니다.
- 원본의 달성률 `2−실적/목표` 방식은 유지합니다. 2024/2025 비교 실적은 2026 보고서에서 원본값을 유지하고, 다른 보고 연도에는 확인되지 않은 이전 연도 수치를 재사용하지 않습니다.

원본 범주에 없는 품목/업체, 원장 누락, 유형 미분류는 화면 확인사항에 표시하고 해당 보고서 원인란에 관련 확인 내용을 넣습니다. 원자재 간 kg/EA 단위를 변환하거나 원본 업체 차트에 없는 공급사를 다른 업체로 임의 분류하지 않습니다.

실제 운영 DB의 보고 수치 대사와 사용자 Excel 환경의 인쇄 결과 승인은 별도 확인이 필요합니다. 개발 검증은 임시 DB/합성 자료를 사용하며 구조·스타일·수식/캐시·브라우저 저장/다운로드를 검증합니다.

전체 앱 회귀 검증은 소스의 별도 임시 복사본과 임시 DB에서 `app.py`를 직접 불러와 9월 화면·조회 API·Excel 다운로드의 HTTP 응답을 확인합니다.
