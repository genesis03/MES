# 자재 사용 현황

재고관리 `/inventory/material-usage`의 독립 수기 대장입니다. 일자, 작업자, 생산품번, 생산 LOT, 총 생산수량(양품·불량·셋업 포함), 자재별 품번·LOT·단위·투입·사용·폐기·잔여·비고를 직접 작성합니다. 생산실적/BOM/품목마스터를 자동 조회하거나 재고를 차감하지 않습니다.

- 총 생산수량은 한 기록에 한 번 작성하며 같은 자재·단위의 여러 투입/사용 행을 합산합니다.
- 개당 소요량과 수기 필요량은 입력/조회/엑셀에서 제거했습니다. 이전 JSON·감사 이력은 보존하지만 해당 값은 현재 계산에 사용하지 않습니다.
- 수불차이 = 투입−사용−폐기−잔여. 네 수량이 모두 있어야 계산합니다. 양수는 사용처 미기록, 음수는 투입 초과 기록입니다. 목록에 행별 차이 수량·단위를 표시합니다.
- 생산 대비 자재 사용 차이 = 같은 자재의 사용 합계−총 생산수량. 자재별 부족/초과 수량과 합계를 별도 열에 표시합니다. 생산 1개당 각 자재 1개 기준의 비교입니다.
- 빈 수량은 0으로 간주하지 않습니다. 미입력이 있으면 해당 합계/비교는 미판정입니다.
- 정상 표시는 입력 기록 간 일치만 의미하며 미기록 자재나 실물 조립 여부를 자동 증명하지 않습니다.

Excel 첫 시트는 일일 조립공정 누락방지 검토 양식입니다. 날짜·생산품번·자재품번·단위별로 집계합니다. 생산수량은 각 기록/자재에 한 번만 반영하며, 취소 기록은 검토에서 제외합니다. 소모율은 사용 합계/총 생산수량×100입니다. 100% 미만은 조립 누락 확인, 105% 이상은 자재 LOSS 증가 확인 대상으로 표시합니다. 실제 누락을 확정하지 않습니다. 날짜별 제목/작성일/작성자/검토방법과 인쇄 구분을 제공합니다. 상세 시트에는 필터에 맞는 원본 수기 행과 수불 차이 내역을 제공합니다.

수정/취소는 사유와 이전/이후 내용을 보관합니다. 동시 수정은 버전 충돌로 차단하며 신규 저장 재시도는 요청 키로 중복을 방지합니다. 기간·생산품번 일부·작업자·확인사항 조회가 가능합니다. READ는 조회/내보내기, WRITE는 작성/수정/취소 권한입니다.

독립 테이블 `material_usage_records`, `material_usage_audits`는 앱 시작 시 생성합니다. 기존 재고 테이블은 변경하지 않습니다.
