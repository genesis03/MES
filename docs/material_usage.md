# 자재 사용 현황

재고관리 `/inventory/material-usage`의 독립 수기 대장입니다. 일자, 작업자, 생산품번, 생산 LOT, 생산수량, 자재별 품번·LOT·단위·필요수량·투입·사용·폐기·잔여·비고를 직접 작성합니다. 생산실적, BOM, 품목 마스터, 재고를 자동 조회하거나 차감하지 않습니다.

- 빈 수량은 미입력으로 유지하며 0과 구분합니다.
- 수불차이는 투입−사용−폐기−잔여입니다. 네 수량이 모두 있어야 계산합니다. 사용·폐기·잔여를 모두 비워도 투입 합계 검증은 가능합니다.
- 총 생산수량은 양품·불량·셋업을 포함하여 한 번 작성합니다. 동일 자재·단위의 여러 투입 행을 합산하고 `총 생산수량 × 개당 소요량`과 비교해 투입 차이·투입률을 표시합니다. 개당 소요량은 한 행에만 작성하며 미입력 시 1을 적용합니다. 기존 수기 필요수량은 입력되어 있으면 우선 적용합니다. 사용량이 입력된 경우에는 사용 합계도 별도로 비교합니다. 예: 생산 2,000개, 자재 투입 500·500·1,000 → 투입 합계 2,000, 차이 0, 투입률 100%.
- 정상 표시는 입력 기록 간 일치만 의미합니다. 미기록 자재나 실물 조립 여부를 자동 증명하지 않습니다.
- 수정·취소는 사유와 이전/이후 내용을 보관합니다. 취소는 원본을 삭제하지 않습니다. 동시 수정은 버전 충돌로 차단하며 신규 저장 재시도는 요청 키로 중복을 방지합니다.
- 기간·생산품번 일부·작업자·확인사항으로 조회하고 전체 조회 결과를 Excel로 내보냅니다. READ 권한은 조회·내보내기, WRITE 권한은 작성·수정·취소가 가능합니다.

새 테이블 `material_usage_records`, `material_usage_audits`는 앱 시작 시 기존 모델 초기화 절차로 생성됩니다. 기존 재고 테이블은 변경하지 않습니다.
