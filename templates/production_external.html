외부 연동 생산실적

최초에는 올해 1월 1일부터 오늘까지, 이후에는 최근 기간의 실적을 자동으로 가져옵니다. 복합선반·탭핑은 호기별 주간·야간 작업일보에서 수량과 상세 내역을 가져옵니다. 조립 AS-01·AS-02 주간은 LOT별 수량·시간과 작업일보 합계가 맞을 때 작업자·주야·상세 정보를 보완합니다. 다른 공정은 기존 생산실적 조회를 사용합니다. 자재 차감·재고·MES 작업지시에는 자동 반영하지 않습니다.

반복 조회는 같은 생산 LOT의 실적을 갱신합니다. 품번·작업번호·공정이 달라도 생산 LOT는 중복 저장하지 않습니다. 내부 LOT와 충돌하거나 같은 LOT가 서로 다른 MES 품목으로 연결되면 해당 날짜의 저장을 중단합니다. 기존 충돌 내역은 확인사항에 표시하며 일반 생산실적 현황에서는 제외합니다.

일반 생산실적 현황에서도 함께 조회됩니다. 총생산수량 = 양품 + 불량 + 셋업입니다. 생성 LOT는 원본 LOT를 표시하며, 작업자·주야·투입 LOT·비가동·불량 유형은 응답에서 확인된 정보를 표시합니다.

품번 연결

BOM에서 해당 공정의 생산품목을 찾아 자동 연결합니다. 복합선반 -A · 탭핑 -B · 세레이션 -D · 은도금 -Ag · 조립 -C · 포장은 완제품입니다. BOM이 없는 경우 같은 기본품번의 공정 품목을 확인합니다. 해당 품목이 없거나 후보가 여러 개면 미연결로 표시합니다. 품번 조회에서 우리 MES 품목을 직접 선택할 수 있으며 수동 연결이 우선합니다. 나중에 품목이나 BOM을 등록하면 기존 실적에도 적용됩니다.
