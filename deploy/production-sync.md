# 생산실적 자동 동기화

관리자 메뉴의 **외부 연동 생산실적**에서 기존 UNI_MES 생산실적을 조회한다.
최초에는 올해 1월 1일부터 오늘까지 가져오고, 성공 완료 이후에는 기본 60분 간격으로 최근 7일을 다시 조회한다. 관리자가 화면에서 계정을 저장한 뒤 자동 동기화 사용을 켠다. 최초 조회가 중간에 실패하면 완료로 표시하지 않고 다음 실행에서 재시도한다.
서버가 실행 중일 때만 동작한다. 자동 조회와 수동 조회는 DB 실행 잠금으로 직렬화한다.

## 연동 계정

관리자 메뉴 → **외부 연동 생산실적** → **연동 계정 설정**에서 아이디와 비밀번호를 입력한다.
**로그인 확인**은 저장하지 않고 인증을 확인한다. **계정 저장**은 로그인 성공을 확인한 후 비밀번호를 암호화해 DB에 저장한다.
같은 아이디에서 비밀번호를 비우면 기존 비밀번호를 유지한다. 최초 저장과 아이디 변경에는 비밀번호가 필요하다.
계정 변경은 다음 동기화부터 서버 재시작 없이 적용되며 동기화 중에는 저장할 수 없다.

암호화 키는 서버의 문서 저장 폴더 상위 경로 `production-sync.key`에 저장한다. 환경변수 `PRODUCTION_SYNC_KEY_PATH`로 별도 경로를 지정할 수 있다.
DB만 다른 서버로 옮기면 암호화 키가 다르므로 해당 서버 화면에서 계정을 다시 저장한다. 키 파일은 별도로 보호·백업한다.
비밀번호와 인증 쿠키는 응답·화면·감사로그에 노출하지 않는다. 일반 계정은 페이지와 관련 API에 접근할 수 없다.

기존 서버 환경변수 `PRODUCTION_SYNC_USER`, `PRODUCTION_SYNC_PASSWORD` 방식도 유지하며, 화면에서 저장한 계정이 우선한다.
암호화 라이브러리 설치를 위해 변경된 `requirements.txt`를 적용하고 최초 한 번 MES 서버를 재시작한다.

## 화면 사용

1. 관리자 메뉴 → 외부 연동 생산실적에서 연동 계정을 저장한다.
2. 자동 동기화 사용, 조회 간격과 최근 조회 일수를 저장한다.
3. 최초 전체 조회가 완료됐는지 상태에서 확인한다. 추가 과거 데이터는 시작일·종료일을 지정하고 **선택 기간 지금 가져오기**를 사용한다(최대 366일).
4. 품번·LOT로 검색하고, 원본 공정명이 MES 공정명과 다르면 공정 연결에서 지정한다.
5. 동기화 이력에서 신규·수정·동일 건수와 실패 날짜 범위를 확인한다. 실패 후 같은 기간을 재조회할 수 있다.

## 데이터 처리 범위

- 외부 실적을 별도 테이블에 저장한다. 기존 MES 실적, 작업지시, 재고, BOM, 자재 차감과 생산 LOT는 변경하지 않는다.
- 품번은 내부 품목 마스터에 연결하고 품명은 마스터를 우선 표시한다. 쉼표 때문에 해석이 모호한 원본 품명은 자동 분할하지 않는다.
- 현재 중복 키는 LOT·작업번호·원본 공정명이다. 동일 키의 수량·시간 변경을 갱신한다. 원본 키 자체가 바뀌면 다른 실적으로 저장될 수 있으며, 키 변경·삭제 자동 반영은 지원하지 않는다.
- 작업수량 JOB_QTY는 양품, FAULT_QTY는 불량, F10은 SET-UP으로 연결한다. LOT_QTY는 전체수량으로 보관하고 양품+불량+SET-UP 합계를 비교한다. 차이가 있으면 확인사항을 표시한다.
- 자동 조회는 최근 기간만 다시 확인한다. 오래된 실적 수정은 수동 재조회가 필요하다.
- 날짜별 응답을 검증하고 날짜별로 저장한다. 중간 실패 시 완료된 날짜를 유지하며 이후 날짜는 저장하지 않는다.
- 원본에서 사라진 행은 자동 삭제하지 않는다. 실제 삭제와 조회 누락을 아직 구분할 수 없기 때문이다.
- 상대 시스템의 공식 외부 API가 아닌 확인된 화면 통신을 사용한다. 상대 화면 통신 변경에 영향을 받을 수 있다.
- 서버가 건수를 제공하면 수신 건수와 대조한다. 일별 조회로 범위를 줄였지만 페이지 처리와 전체 건수는 추가 확인이 필요하다.
- 신규 테이블은 기존 프로젝트 방식대로 다음 서버 시작 시 생성한다. 기존 테이블을 수정하거나 DB를 옮기는 작업은 수행하지 않는다.

## 서로 다른 품번과 사후 등록

MES에 없는 품번도 외부 실적 원본으로 보관한다. 나중에 품목을 등록하고 연결하면 기존에 가져온 실적에도 즉시 적용된다.
품번 연결은 **원본 품번 + 원본 공정 → MES 품목 ID**로 저장한다. 두 시스템의 품번 표기가 달라도 연결할 수 있으며, 원본 품번은 변경하지 않는다.
자동 연결은 원본 품번의 공정 접미사(-A/-B/-D/-Ag/-C)를 제거한 기본품번에 해당 공정 접미사를 적용한다. 복합선반 -A, 탭핑 -B, 세레이션 -D, 은도금 -Ag, 조립 -C, 포장은 접미사가 없는 완제품 품번이다. 연결한 MES 공정명을 우선하고 원본 공정명도 확인한다. 사용 중인 등록 품목이 하나일 때만 연결하고, 없거나 대소문자만 다른 후보가 여러 개면 미연결로 표시한다. 알려지지 않은 공정은 동일 품번만 연결한다. 숫자 접미사 등 다른 품번 체계는 추측하지 않고 수동 선택한다.
품번 조회에서는 전체 사용 중인 MES 품목을 검색하고 해당 공정의 품목을 먼저 표시한다. 직접 지정한 연결이 자동 연결보다 우선한다. '자동 연결로 전환'은 수동 지정을 제거하고 현재 공정별 규칙을 다시 적용한다. 생산 LOT나 재고를 변경하지 않는다.

## 현재 생산실적 양식과의 대응

외부 연동 실적 화면은 현재 생산 실적 현황과 같은 열 순서로 표시한다. 공정 연결에서 가공/조립 구분을 지정할 수 있다.
생산 LOT에는 수신한 원본 LOT를 표시한다. 생산호기는 원본 LOT의 끝에서 두 번째 자리 숫자로 표시한다(예: LX20261009065 → 6). 해당 자리가 숫자가 아니면 미확인으로 표시한다. 별도의 MES 생산 LOT나 재고를 생성하지 않는다. LOT 차감·투입 LOT·작업자·주야·MES 작업지시는 확인되거나 연결되기 전까지 미확인/미연결로 표시한다. 숫자 0으로 대체하거나 임의로 계산하지 않는다.
양품·불량수량과 원본 보기의 LOT수량은 소수점 없이 정수로 표시한다. 원본 저장값은 유지한다. 작업수량·LOT수량·F10·원본 LOT와 작업번호는 원본 보기에서 확인한다.
F10은 SET-UP 수량으로 표시한다. LX20260325016의 F10=115가 사용자가 확인한 SET-UP=115와 일치했고, 원본 242행 모두 LOT_QTY=JOB_QTY+FAULT_QTY+F10 관계가 성립했다. 원본 값도 함께 유지한다.
