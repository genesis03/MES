# 외부 입고현황 연동

외부 데이터 연동의 다섯 번째 대상 `입고현황`입니다. 기존 생산실적 계정·동적 접속키를 공유하며, 공통 자동 설정·날짜 지정 수동 가져오기·연동 이력에서 사용할 수 있습니다. 신규 대상의 자동 연동은 기본 중지이며 기존 설정은 유지합니다. 입고현황을 체크하고 공통 설정을 저장하면 활성화됩니다.

- 원본: `MES.In.InConfirmList.InConfirmListObj`, `List`.
- 요청 날짜: `MES.In.InDetailList.InDetailListCondSet.IN_DATE1/IN_DATE2`. 지정 기간을 월별 요청 구간으로 나누고 서버 경계 차이를 위해 앞뒤 하루를 포함해 조회합니다. 반환된 날짜가 개별 요청 범위를 벗어나더라도 실패시키지 않으며, 최종 저장은 사용자가 지정한 전체 기간의 실제 입고일(IN_DATE)로 제한합니다. 확정일(CONFIRM_DATE)은 별도로 보존합니다.
- 수량: 빈 IN_QTY 대신 CONFIRM_QTY(확정수량)를 사용합니다.
- 거래처: 공백을 제거한 이름이 `테스트거래처`인 항목을 제외합니다. 다른 이름에 ‘테스트’가 포함된 경우까지 임의 제외하지 않습니다.
- 품번: 원본 품번 그대로 보관하고 품명·단위는 내부 품목마스터의 유일한 정확 일치 품번에서 조회합니다. 원본에는 단위가 없어 미연결 항목은 —이며 EA/kg로 추정하지 않습니다. 외부 품명은 저장/분석 기준으로 사용하지 않습니다.
- 원자재/반제품 모두 연동하며 화면에서 구분 필터를 제공합니다. 품질보고서에 넣을 때는 원자재 분류를 선택해야 합니다.
- 동일 이력번호(HIS_NUM)·품번은 갱신합니다. 같은 이력번호에 다른 품번이 있어도 누락하지 않습니다. 같은 이력·품번에 업무 필드가 모두 같은 여러 행은 확정수량을 합산하되 연결이 모호하면 저장을 중단합니다. 월별 요청 구간이 겹쳐 같은 이력이 다시 반환돼도 요청 간에는 합산하지 않습니다. 수신 건수는 이러한 이력·품번 묶음 기준입니다.
- 정상 기간 조회에서 사라진 행은 해당 저장 기간 안에서만 원본 누락으로 표시합니다. 단, 외부 날짜 조건과 실제 입고일이 다르게 반환된 응답에서는 기존 자료의 누락·취소 판정을 보류하고 이력에 확인사항을 남깁니다. 기간 중 어느 요청이 실패해도 전체 저장 전 중단하므로 부분 응답으로 기존 자료를 덮지 않습니다. 재등장한 행은 복원합니다.
- 일반 자동 실행은 설정한 최근 기간만 처리하며 기존 과거 날짜를 추가 조회하지 않습니다. 최초 실행은 다른 항목처럼 올해 1월부터 가져옵니다. 과거 변경/취소나 날짜 이동은 이전/새 날짜를 포함한 수동 재연동으로 반영합니다.
- 독립 external_inbound_records 원장으로 보관하며 기존 구매입고·재고·LOT를 생성/변경하지 않습니다. 불량수량을 가져오는 API는 아닙니다. 보고서 원자재 불량 0 적용은 별도 보고서 집계 정책입니다.

첨부 응답 검증: 15행 중 테스트 거래처 2행을 제외해 13행이며, 원자재 11행·반제품 2행입니다. 동소재 확정수량 숫자 합은 7,368이며 단위는 원본에 없어 이 숫자만으로 kg/EA를 확정하지 않습니다.

페이지/필드 수·날짜·확정 상태·수량을 검증합니다. 확인되지 않은 페이지 처리에서 표시 건수 누락 상태로 25의 배수 행에 도달하면 전체 수신으로 단정하지 않고 중단합니다.

운영에는 코드 업데이트와 앱 재시작이 필요합니다. 신규 테이블은 기존 모델 초기화 절차에서 생성합니다. 실제 외부 서버 로그인/조회는 운영 연동 계정으로 실행해야 하며, 개발 검증은 첨부 응답 및 임시 DB에서 수행합니다.

## 일반 입고 조회 표시

`구매관리 → 입고 조회`의 전체/일반구매 탭에도 외부 입고현황을 표시합니다. 자료 구분(전체/MES/외부 연동)으로 나눠 볼 수 있으며 날짜·거래처·품번 일부·입고번호·입고확정 상태 필터를 적용합니다. 외부 원본에서 확인하지 못한 발주번호/LOT 조건으로는 외부 행을 반환하지 않습니다. 원본 누락 행은 통합 조회에서 제외합니다.

외부 자료는 별도 조회 API `/api/purchase/inquiry/external-inbounds`로 읽고, ‘외부 연동’ 표시와 조회 전용 동작을 제공합니다. 수정 링크·선택삭제·전체 선택 대상에서 제외하며 일반 구매입고 입력/수정용 자료 선택기에는 섞이지 않습니다. 외부와 내부 입고의 동일 날짜·수량만으로 임의 중복 제거하지 않습니다. 이 연결은 조회에 한정하며 기존 입고·재고·LOT는 생성하거나 변경하지 않습니다.
