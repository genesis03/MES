# 출하 성적서와 통합 공정 현황

## 출하 성적서

품질관리 → 출하 성적서에서 품번으로 현행 최종검사 기준서를 불러옵니다.
복수 현행 기준서가 있으면 사용자가 선택합니다. 1~27항목과 시료 5개를 지원합니다.
규격·계측기·기준서 개정·품목명은 등록 당시 스냅샷으로 보존합니다.
검사자는 로그인 계정으로 기록하며 클라이언트가 보낸 판정이나 규격은 사용하지 않습니다.
등록한 성적서는 조회·출력할 수 있고 덮어쓰지 않습니다.

- 상·하한이 있으면 개별 값 모두를 비교합니다. 경계값은 합격입니다.
- 하나라도 규격 이탈이면 NG입니다. 평균이 규격 내여도 NG입니다.
- 누락 시료가 있으면 HOLD이며 모든 항목이 OK일 때만 PASS입니다.
- 수치 규격이 없는 외관 항목은 OK/NG를 직접 선택하며 미선택은 HOLD입니다.
- 검사결과는 재고 합격처리·출고 확정을 자동으로 실행하지 않습니다.

`assets/InspectionReport_Template.xlsx`는 이번 기능을 위해 작성한 기본 양식입니다.
회사 승인 서식이라고 간주하지 않습니다. 런타임에는 기존 파일을 열어 데이터만 입력합니다.
서식 생성 도구는 `scripts/build_inspection_report_template.py`이며 서버 시작 시 실행하지 않습니다.
회사 양식으로 교체할 경우 다음 쓰기 영역은 일반 셀 또는 병합 시작 셀이어야 합니다.

| 영역 | 값 |
|---|---|
| C3/C4/C5 | 관리번호/품번/품명 |
| G3/G4/G5 | 검사일/LOT/시료 수 |
| K4 | 작성자 |
| B10:M36 | 순번·구분·항목·규격·계측기·실측 5개·평균·판정 |
| L38/C39 | 종합판정/특기사항 |

`inspection_report_masters`와 `inspection_report_items`는 기존 Base를 통해 생성됩니다.
기존 업무 테이블이나 DB 설정은 변경하지 않습니다.
일반 계정은 기존 계정 관리에서 출하 성적서의 READ/WRITE 권한을 부여합니다.
API도 헤더·Referer에 의존하지 않고 해당 권한을 확인합니다.

## 통합 공정 현황

생산관리 → 통합 공정 현황입니다. 미출하 수주를 수주일·전표 ID·항목 ID 순으로 처리합니다.
동일 품목의 가용 LOT는 등록일·LOT 순으로 수주에 중복 없이 예정 배정합니다.
포장 재고와 일반 완제품 재고는 별개 공급으로 한 번씩만 계산합니다.
기존 LOT 재고 조회를 재사용하여 소비·취소·수동조정·외부 포장 중복 방지 정책을 유지합니다.

예: 미출하 100, 완제품 20, 포장 0 → 준비율 20%, 신규 생산 필요 80.
진행 지시 50이 있으면 신규 생산 필요 80 중 지시 예정 연결 50, 미연결 30입니다.
진행 작업지시는 아직 완제품이 아니므로 출하 준비율을 올리지 않습니다.
필터링 전 전체 수주를 배정하므로 품번 필터가 재고 배정 순서를 바꾸지 않습니다.
조회는 실제 재고 예약이나 생산지시·수주 간 확정 연결을 저장하지 않습니다.
다음 조회 시 현행 거래로 다시 계산하며, 확정 출고의 실제 LOT 연결은 별도로 표시합니다.

공정별 수량은 동일한 의미의 진척률이 아닙니다.

| 단계 | 기준 |
|---|---|
| 수주 | 취소·완료 제외 미출하 수량 |
| 계획 | BOM 연결 품목들의 등록된 누적 계획량 |
| 지시 | 대기·진행 지시의 미생산 잔량 |
| 가공 | BOM 연결 가공 품목의 현재 LOT 잔량 |
| 외주도금 | 정상 외주 출고에서 정상 입고를 뺀 수량 |
| 검사 | 외주입고 검사 미완료이며 현재 LOT에 남아 있는 수량 |
| 조립 | BOM 연결 조립 품목의 현재 LOT 잔량 |
| 비전 | 별도 원장 부재로 미집계 |
| 포장 | 미출고 포장 재고 |

품명으로 연결하지 않고 품목 ID와 BOM을 사용합니다.
공용 BOM 품목은 여러 완제품 행에 표시될 수 있으며 합산하지 않습니다.
공정 수량은 각 품목의 EA이며 BOM 소요량으로 완제품 환산한 수량이 아닙니다.
따라서 서로 다른 단계의 수량을 더하거나 이를 생산 완료율로 표시하지 않습니다.
외부 가공·조립 응답의 생산수량은 현재 재고 잔량이 아니므로 재고로 승격하지 않습니다.
외부 포장은 기존 외부 포장 재고 연결 정책에 따라 포함됩니다.
작업지시 예정 배정은 수주와 동일한 완제품 품목의 지시에만 적용합니다.
반제품 지시를 완제품 수주에 자동 연결하려면 BOM 소요량·공용부품 예약 정책이 추가로 필요합니다.
