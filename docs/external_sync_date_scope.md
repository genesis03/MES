# 외부 자료 연동 날짜 범위

일반 자동 연동(AUTO)은 연동 이력에 기록된 시작일~종료일만 처리합니다. 포장현황·외주불량·출고이력에서 이미 저장된 과거 날짜를 추가로 재조회하던 동작은 제거했습니다. 설정한 최근 일수는 오늘을 포함하며 출고이력은 내일까지 포함합니다. 최초 연동(INITIAL)의 올해 1월 1일부터 가져오는 기존 동작은 유지합니다.

수동 연동(MANUAL)은 지정 기간만 처리합니다. 과거 자료를 수정·취소한 경우 원본 날짜(포장일/검사일/출고일)를 포함해 다시 가져오세요. 원본의 날짜 자체가 변경됐다면 이전 날짜와 새 날짜를 모두 포함해야 합니다. 포장 출고 취소는 원래 포장일을 다시 조회해야 포장재고에 반영됩니다.

범위 밖 기존 자료는 이번 조회에서 다시 읽거나 제거하지 않습니다. 조회 범위 내의 정상 응답에 대한 갱신·취소 처리와 부분 실패 보호는 기존대로 동작합니다. 외부 서버의 날짜 경계 차이를 보완하기 위해 개별 요청은 앞뒤 하루를 포함할 수 있지만, 날짜 필터 후 해당 일자의 기록만 저장하고 건수에 합산합니다.

기존 연동이력은 과거 실행 당시 결과로 보존합니다. 변경 배포 후 시작하는 실행부터 새 범위를 적용합니다.
